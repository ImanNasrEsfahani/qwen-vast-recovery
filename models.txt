Qwen Image Edit 2511 — Core files
==================================

Core model files installed by bootstrap.sh:

1) qwen_image_edit_2511_fp8mixed.safetensors
   -> ComfyUI/models/diffusion_models/

2) qwen_2.5_vl_7b_fp8_scaled.safetensors
   -> ComfyUI/models/text_encoders/

3) qwen_image_vae.safetensors
   -> ComfyUI/models/vae/

4) Qwen-Image-Edit-2511-Lightning-4steps-V1.0-bf16.safetensors
   -> ComfyUI/models/loras/

Custom LoRAs
------------
Additional user LoRAs also go in:

ComfyUI/models/loras/

Use install-lora.sh to download one directly on the Vast.ai instance.

Important:
A LoRA must be compatible with Qwen-Image / Qwen-Image-Edit-2511. A LoRA made for SDXL,
Flux, Wan, or another base model is not automatically compatible.
